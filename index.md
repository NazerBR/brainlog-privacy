# BrainLog

BrainLog is a private, single-user assistant operated by its owner for their own notes,
tasks and reminders. It is not offered to the public and has no sign-up.

With the owner's consent, it reads the owner's Gmail messages and Google Calendar events to
answer the owner's questions and suggest tasks and reminders in the owner's private Telegram
chat. If the owner also allows it, BrainLog can save an email as a Gmail draft for the owner
to check, send that draft when the owner taps Send, and add an event to the owner's calendar
when the owner taps Confirm.
